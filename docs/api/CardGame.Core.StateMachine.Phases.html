Namespace CardGame.Core.StateMachine.Phases

Classes

ActionPhaseState

Handles the Action Phase where players can only play action cards (spells) and not units.

BothPhaseState

Handles the Combined Phase where players can play both units and action cards (spells).

CombatPhaseState

Handles the Combat Phase where units battle each other and the phase transitions to the next round.

MulliganPhaseState

Handles the Mulligan Phase where players can replace cards from their initial hand before the game begins.

UnitPhaseState

Handles the Unit Phase where players can only play unit cards and not action cards.
