Controls the visual representation of a single card in the game UI. Handles rendering card data (stats, text, art), input interactions (hover, click), and visual states (highlighting, selection).

Methods

Render(CardInstance)

Updates the card's visual state based on the provided card data. Sets text, stats, colors, and art.

RenderCardBack()

Renders the card back (face down state). Hides all stats and text, shows a card back texture or color.

SetHighlight(bool, Color)

Toggles the visual highlight effect on the card border.

SetMulliganSelected(bool)

Sets the visual state for Mulligan selection (e.g., overlay X).

UpdateCount(int, int)

Updates the visual count badge (used in Deck Editor).

_GetDragData(Vector2)

Generates drag data when the user starts dragging the card. Creates a visual preview of the card under the cursor.

_GuiInput(InputEvent)

Handles GUI input events directly on the card control. Detects left clicks to trigger interaction.

_Ready()

Initializes the card view, setting default size, mouse filter, and visual properties. Configures child controls to scale properly.
