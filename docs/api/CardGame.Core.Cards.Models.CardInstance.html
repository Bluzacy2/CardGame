Class CardInstance

Namespace
CardGame.Core.Cards.Models
Assembly
CardGame.Core.dll

Represents an instance of a card in the game with mutable state such as damage taken and buffs. Each card instance is immutable and returns new instances when modified.

Methods

AddPermanentBuff(CardStats)

Adds a permanent stat buff to the card and returns a new instance. Silenced cards cannot receive buffs.

Heal(int)

Heals the card and returns a new instance.

MoveAndReset()

Creates a new card instance with all state reset to default (except InstanceId, Owner, and Definition). Typically used when moving a card between zones.

Silence()

Silences the card, removing all buffs, keywords, and auras, and returns a new instance.
