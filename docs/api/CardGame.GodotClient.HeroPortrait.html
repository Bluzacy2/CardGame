Visual component representing a player's hero. Displays Health, Resources (Blood), and the Avatar image. Handles interactions like targeting the hero with spells and receiving dropped cards.

Determines whether the dragged data can be dropped onto the hero portrait. Accepts data of type int (representing a Card Instance ID).

Handles the drop event when a card is released over the hero portrait. Useful for playing cards directly on the hero (e.g., direct damage spells or buffs).
